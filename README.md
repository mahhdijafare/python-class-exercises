
# Python Class Exercises

This repository contains three Python exercises.

## Exercises

 1. Basic - Number Checker
Checks whether a number is positive, negative, zero, even, or odd.

2. Intermediate - Movie Ticket Pricing
Calculates the movie ticket price based on age.

3. Advanced - Leap Year Checker
Checks whether a Gregorian year is a leap year.
