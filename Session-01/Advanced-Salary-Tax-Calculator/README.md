
# Advanced Salary Tax Calculator

## Description
A simple Python program to calculate employee salary tax.

 Tax Rules
- Up to 10 million Toman: 0% tax.
- Between 10 and 25 million Toman: 10% tax on the extra amount.
- Above 25 million Toman: 20% tax on the extra amount.

Special Condition
If the employee has a child, 500,000 Toman is deducted from the final tax.

Programming Language
Python
